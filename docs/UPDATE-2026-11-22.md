# 2026-11-22 更新说明

本次更新解决个人单账号自动化场景中审批门过度防御的问题：普通任务连续触发多张审批卡，影响执行效率，但没有带来与操作风险相匹配的安全收益。

本说明仅沉淀脱敏后的通用原则、风险边界和验收结论，不包含生产路径、网络地址、身份信息、会话标识、凭据、运行日志、私有业务细节或新版运行时代码。

## 一、问题定位

此前审批策略将个人可信会话中的日常操作近似按多租户、不可信调用环境处理。只要不是纯只读操作，写文件、执行命令、读取工作区外内容或进行已授权的日常平台操作，就可能逐次要求确认。

同一任务因而反复中断，出现多张甚至十余张审批卡。根因不是这些普通操作全部具有高风险，而是默认确认策略没有区分可信主体、资源边界与操作后果，属于防御性编程的适用场景失配。

本次修正不以“全部放行”为目标，而是将审批集中到真正涉及破坏、秘密、越界和高影响外部副作用的行为。

## 二、改动原则：增加信任会话层

新增概念上的信任会话层（trusted tier），只对同时满足以下条件的操作适用低摩擦策略：

- 请求来自已经通过现有认证的本人登录会话；
- 读写或执行范围处于受信任的部署工作区内；
- 目标不是敏感文件、安全配置或受保护资源；
- 行为属于普通、可控、非危险操作，且没有越过既有授权范围。

信任会话层只是限定范围内的日常操作豁免，不是全局关闭审批，也不是对任意命令、任意路径或任意外部平台授予无限权限。路径范围、敏感资源、危险行为和高影响操作仍由独立安全规则判断。

风险判断应依据主体、作用范围、实际后果与可恢复性，而不是只依据“是否写入”或“是否执行命令”。

## 三、新增免审批范围

在信任会话层条件全部满足时，以下操作可直接执行：

- **普通文件操作**：读取、创建、写入、编辑和删除工作区内的非敏感普通文件；
- **日常命令执行**：在受信任工作区中运行非危险命令，包括常规检查、测试和构建等；
- **工作区内读取**：读取普通工作文件，无需因文件访问动作反复确认；
- **已登记平台的优惠权益领取**：仅在平台已登记、操作已获授权、范围明确且不涉及下单或支付时免逐次审批。

免审批不覆盖敏感路径、越界访问、大范围不可恢复删除，也不意味着自动允许后续资金交易或其他高影响外部动作。

## 四、仍保留的审批与拒绝

以下边界继续生效，依风险性质要求单独确认或直接拒绝：

- **危险命令**：例如 `rm -rf`、`sudo`、`dd`、`mkfs`、`shutdown`、`reboot`、`halt`、`systemctl stop`、`systemctl disable`、`killall` 等，不能因会话可信而自动放行；
- **敏感资源**：SSH 认证目录（如 `.ssh`）、环境和凭据文件（如 `.env`）、密钥、凭据及安全或技能配置目录（如 `.dsh`）；
- **工作区外访问**：超出受信任部署工作区的读取、写入、移动或删除，不能套用工作区内免审批规则；
- **第三方扩展**：加载或执行未经审核的第三方技能，不因处于本人会话而自动取得信任；
- **不可恢复破坏**：删除系统根目录、写入块设备及其他可能破坏系统或数据的操作；
- **金融与秘密操作**：支付、最终下单、转账、凭据导出，以及把秘密发送到外部。

明确禁止的操作应直接拒绝，允许但影响较大的操作应走必要的确认流程；不能把两者都简化为普通免审批操作。

## 五、验收结果

根据本次服务器侧变更的端到端验收记录：

- 工作区内普通写文件、编辑及非危险命令执行已验证无需反复弹出审批卡；
- 危险命令、敏感路径和工作区外访问仍触发相应审批或拒绝，核心边界未随信任会话层一起放开；
- 回归测试全部通过；
- 服务重启后正常运行，未出现崩溃重启循环；
- 完整性哈希核验确认运行进程加载了本次更新后的策略代码。

以上属于服务器生产实现的验收结论。公开仓库未引入新版运行时代码，也不以此文档宣称旧版参考实现已经部署或通过同一组运行时测试。

## 六、与公开仓库的关系

公开仓库保存的是历史 Execution Gate 脱敏参考实现及其风险分级模型；本次服务器上实际使用的 DSH 是独立演进的运行时架构。两者不能仅凭相近的审批概念视作同一套代码。

因此本次只补充更新说明，不替换旧版风险解析、路径策略或自动化作用域等源码，不复制服务器私有部署规则，也不引入新版运行时依赖。

## 总结

这次校准修正的是“普通个人自动化默认逐项确认”的过度防御，而不是取消安全控制。

```text
可信本人会话 + 受信任工作区 + 普通操作 → 直接执行
敏感路径或工作区外访问 → 保留审批或拒绝
危险命令与不可恢复破坏 → 严格限制
支付、下单、转账、凭据导出 → 单独严格保护
```

安全边界应跟随真实风险，而不是让一个正常任务被低风险操作反复打断。
